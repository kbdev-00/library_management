# 📚 Library Management System

A web-based Library Management System built using **Java, Servlets, JSP, JDBC, Oracle SQL, HTML, CSS, and JavaScript**.

The application helps manage library operations such as book management, user management, issuing and returning books, and tracking library records.

## 🛠️ Technologies Used

- Java
- Servlets
- JSP
- JDBC
- Oracle SQL
- HTML5
- CSS3
- JavaScript
- Apache Tomcat
- MVC Architecture

## ✨ Features

- User registration and login
- Add, update, delete, and view books
- Search books
- Issue books
- Return books
- Manage users
- Track issued books
- Oracle database integration
- MVC-based project structure

## 🏗️ Architecture

JSP → Servlet → Service → DAO → JDBC → Oracle Database

## 🎯 Purpose

This project was developed to understand **Java web development, Servlet/JSP architecture, JDBC database connectivity, CRUD operations, and MVC design patterns**.
